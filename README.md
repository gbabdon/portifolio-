# 💻 Portfólio — Gabriel Abdon

> Portfólio pessoal interativo desenvolvido como parte de uma atividade acadêmica do curso de Engenharia de Software.

---

## 👨‍💻 Sobre o projeto

Este projeto consiste na criação de um portfólio pessoal e interativo desenvolvido no Figma.

O objetivo do portfólio é apresentar minha trajetória acadêmica, meus interesses, habilidades, objetivos e projetos relacionados à área de tecnologia.

A identidade visual foi desenvolvida com inspiração em **programação e código Python**, utilizando elementos visuais semelhantes a editores de código, terminais, linhas de código e syntax highlighting.

O projeto também conta com um protótipo interativo, permitindo navegar entre as diferentes seções do portfólio e acessar páginas individuais dos projetos.

## 🎨 Design do portfólio

A identidade visual do portfólio foi criada com uma estética inspirada em **código Python e interfaces de desenvolvimento**.

Entre os principais elementos utilizados estão:

- Interfaces semelhantes a editores de código;
- Linhas de código;
- Syntax highlighting;
- Elementos de terminal;
- Tipografia monoespaçada;
- Janelas e abas;
- Elementos inspirados em Git e programação;
- Microinterações;
- Navegação interativa.

A paleta visual utiliza principalmente tons escuros, com elementos de destaque inspirados nas cores presentes na identidade visual do projeto.
